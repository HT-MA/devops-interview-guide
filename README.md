# DevOps Interview Handbook

DevOps / SRE / 云原生工程师面试知识库

## 内容

- **Linux** - 进程管理、内存分析、CPU分析、网络配置、Shell脚本
- **Docker** - 容器基础、镜像优化、网络配置、存储、安全
- **Kubernetes** - Pod生命周期、Service、Ingress、存储、网络、调度
- **CI/CD** - 流水线设计、Jenkins、GitHub Actions、ArgoCD
- **监控告警** - Prometheus、Grafana、告警管理、日志收集
- **SRE** - SLO/SLI/SLA、故障管理、可观测性
- **场景题** - CPU飙高、内存泄漏、网络故障、Pod崩溃等
- **Terraform** - IaC基础、状态管理
- **Ansible** - Playbook、角色管理

## 特点

- 高频面试题
- 场景化分析
- 真实生产案例
- 持续更新

## 快速开始

```bash
# 安装依赖
npm install

# 本地开发
npm start

# 构建生产版本
npm run build
```
